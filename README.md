# Personal portfolio gateway

**A lightweight entry point to Srishty Pahujani's product portfolio.**

This repository contains a self-contained static gateway linking to my main website and selected public projects. It requires no application build or backend.

[Main personal website](https://srishtypahujani.com/) · [GitHub portfolio index](https://github.com/Srishty-PM/cv) · [LinkedIn](https://www.linkedin.com/in/srishtypahujani/)

## Featured work

- [STYLST](https://github.com/Srishty-PM/stylst): consumer AI, wardrobe matching and outfit planning.
- [Product Intelligence Agent](https://github.com/Srishty-PM/product-framework-improvedagent): guided product analysis and deliverables.
- [Sentinel Lite](https://github.com/Srishty-PM/sentinel-lite): an interpretable AI support-bot evaluation prototype.

## Run locally

```sh
git clone https://github.com/Srishty-PM/srishtypahujani.github.io.git
cd srishtypahujani.github.io
python3 -m http.server 8000
```

Open `http://localhost:8000`, or open `index.html` directly. HTML and CSS live in that file.

The main personal website is maintained separately; this repository is a gateway rather than its complete application source. For career experience and results, use [srishtypahujani.com](https://srishtypahujani.com/).
